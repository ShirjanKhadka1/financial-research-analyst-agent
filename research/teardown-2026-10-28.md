## What "better" means here — the synthesis, not a copy
1. **Deterministic core, LLM optional** — every other repo dies without keys. This one runs fully offline, $0, in Python 3.10+ with zero dependencies. An LLM may write prose on top, it may never compute a number.
2. **Valuation by company type** (from sushpr) — bank, stable, high-growth, cyclical, with stated weights, re-weighted over available models.
3. **Debate + Risk Veto** (from TradingAgents) — Bull vs Bear scored from computed numbers, Risk Manager can veto to zero and cannot be overridden by a story.
4. **Hash-chained audit log** (from ai-hedge-fund) + **$0 default spend** (from the governed topic repo) — tamper-evident, free by construction.
5. **Piotroski F-Score + technicals + VaR/CVaR + Monte Carlo + sentiment lexicon with word counts** — the tools-topic ideas, in one pipeline.
6. **Point-in-time + falsifier on every report** — every input stamped as_of; every verdict states what would flip it.
7. **Stdlib HTTP API, not FastAPI** — /health, /research, /demo with no install, keeping the zero-dependency promise kingabzpro breaks.
8. **Research only, never a trade, never buy/sell** — the advice trap the Claude plugin and several topic repos fall into.
9. **Nepal-ready** — same pipeline takes a CSV price file (NEPSE-style, user-labelled) as it takes Yahoo data; no US-only assumption like sushpr's S&P 500 scope.
10. **Tested, not vibes** — 4 pipeline tests now, including audit-tamper detection and risk-veto firing, versus fakher's un-evidenced suite.
